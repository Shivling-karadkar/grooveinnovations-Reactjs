🚀 Landing Page UI (React.js) 📌 Project Overview This project is a Landing Page UI created as part of my assignment/task to demonstrate my ability to: - Design a modern website interface using a drag-and-drop UI tool (such as Figma, Framer, or similar). - Export the design into HTML/React.js code. - Implement responsive and clean UI components (Header, Hero, Features, Footer). - Showcase the project on GitHub Pages for easy access during interviews. The landing page replicates a professional company website layout with a fixed header, hero section with overlay, feature highlights, and footer.

🖼️ Features Implemented ✅ Fixed Header with navigation & call-to-action button. ✅ Hero Section with background image, transparent overlay, and buttons. ✅ Responsive Design (works on desktop & mobile). ✅ Clean Modern UI styled with CSS. ✅ Code Generated from drag-and-drop design tool, customized and optimized. ✅ Deployed on GitHub Pages. ⚙️ Tech Stack Frontend: React.js, HTML5, CSS3 UI Design Tool: Drag-and-drop builder (e.g., Figma/wordpress etc.)

📂 Project Structure ├── src │ ├── components │ │ ├── Header.js │ │ ├── Hero.js │ │ ├── Features.js │ │ └── Footer.js │ ├── App.js │ ├── index.js │ └── styles │ ├── LandingPage.css │ └── Hero.css ├── public │ └── assets (images, logos, backgrounds) ├── package.json └── README.md

How To Run

Install dependencies
npm install npm start
